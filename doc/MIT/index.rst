Model Independent Transactions
##############################

OSVVM Model Independent Transactions were developed and are maintained by Jim Lewis of SynthWorks VHDL Training. These
evolved from methodology and packages developed for SynthWorks' VHDL Testbenches and verification class. They are part
of the Open Source VHDL Verification Methodology (OSVVM) model library (osvvm_common), which brings leading edge
verification techniques to the VHDL community.
